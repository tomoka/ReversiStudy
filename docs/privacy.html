プライバシーポリシー

最終更新日: 2026年9月20日

本ポリシーは、Android アプリ「リバーシ」（パッケージ名 io.github.tomoka.reversi、以下「本アプリ」）に適用されます。

収集する情報

本アプリは、利用者に関するいかなる情報も収集しません。

具体的に、以下のいずれも取得しません。

  • 氏名、メールアドレスなどの個人情報
  • 端末の識別子（広告 ID、端末 ID など）
  • 位置情報
  • 連絡先、写真、ファイルなど端末内のデータ
  • アプリの利用状況、操作履歴、クラッシュ情報

通信

本アプリはインターネットに接続しません。 本アプリは Android の通信権限（android.permission.INTERNET）を含め、 いかなる権限も宣言していません。この事実は AndroidManifest.xml を見ることで、どなたでも確認できます。

端末内に保存されるもの

対局中の盤面と手番を、画面の回転などでアプリが再作成される際に復元するため、 Android の標準的な仕組み（インスタンス状態）で一時的に保持します。 これはアプリを終了すると失われ、外部に送信されることはありません。

本アプリは、これ以外に端末内へデータを保存しません。

第三者への提供

収集する情報が存在しないため、第三者へ提供する情報もありません。 広告、アクセス解析、その他の外部サービスは一切組み込んでいません。

お子様の利用について

本アプリは情報を収集しないため、年齢にかかわらず安全にご利用いただけます。

ポリシーの変更

本ポリシーを変更する場合は、このページを更新します。 変更の履歴は GitHub のコミット履歴 で確認できます。

お問い合わせ

本アプリおよび本ポリシーに関するお問い合わせは、GitHub の Issues までお願いします。

Privacy Policy

Last updated: September 20, 2026

This policy applies to the Android app "Reversi" (package io.github.tomoka.reversi).

Information we collect

This app collects no information about its users.

It does not collect personal information, device identifiers, advertising IDs, location, contacts, files, usage data, or crash reports.

Network access

This app does not connect to the internet. It declares no Android permissions at all, including android.permission.INTERNET. Anyone can verify this in the AndroidManifest.xml.

Data stored on your device

The app temporarily retains the current board and turn through Android's standard instance state mechanism, so a game survives events such as screen rotation. This is discarded when the app closes and is never transmitted anywhere. No other data is stored.

Third parties

There is no data to share. The app contains no advertising, analytics, or other third-party services.

Changes

Any changes will be published on this page. The revision history is visible in the GitHub commit log.

Contact

Please use GitHub Issues for any questions about this app or this policy.
